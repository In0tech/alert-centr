# Архитектура и выполненные изменения

## Исходное состояние

Старое приложение объединяет Flask, Flask-Login, SQLAlchemy и несколько встроенных Dash-приложений. Dash callback-функции напрямую вызывают `services.data_fetcher`, преобразуют pandas DataFrame и одновременно формируют UI. Это затрудняет тестирование, повторное использование данных и независимое развитие интерфейса.

## Новая граница компонентов

```text
React frontend -> REST API -> application services -> source adapters
                                      |-> OpenSearch
                                      |-> MSSQL
                                      |-> SQLite/PostgreSQL
```

Frontend не импортирует Python-код и не зависит от Dash. Backend не создаёт HTML и возвращает только JSON.

## Уже выполнено

1. Создан отдельный каталог `new-app`.
2. Добавлен FastAPI backend с `/health`, `/api/v1/alerts` и `/api/v1/alerts/{alert_uid}`.
3. Добавлены Pydantic-модели, фильтрация по статусу и уровню, CORS и конфигурация через окружение.
4. Создан React + TypeScript dashboard в визуальной стилистике прототипа.
5. Реализован API-клиент, состояния загрузки/ошибки, KPI-карточки и таблица алертов.
6. Добавлены Dockerfile для обоих компонентов и Docker Compose.

## Безопасность

`SECRET_KEY` больше не должен храниться в исходном коде. Реальные пароли, DSN, токены и адреса внутренних систем должны задаваться через `.env` или секреты платформы развертывания.
